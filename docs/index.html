Шаг 1

Подключаем MCP-коннектор в Claude

Бесплатный Claude подключает один сторонний MCP-сервер — custom connector. Выберите свой вариант:

Вариант А Общий инстанс — ноль усилий

Сервер уже развёрнут и публичен. Скопируйте адрес:

https://astro-mcp-2t5g.onrender.com/mcp

⚠ Инстанс общий и бесплатный: после «сна» первый запрос может подождать ~50 секунд. Если для вас важна приватность — разверните свой (вариант Б): через общий сервер проходят параметры запросов (города, даты).

Вариант Б Свой инстанс одной кнопкой — ~5 минут, без карты

  1. Нажмите кнопку Deploy to Render.
  2. Войдите через GitHub — аккаунт бесплатный, банковская карта не нужна.
  3. Подтвердите имя сервиса (astro-mcp) и нажмите Apply. Render ничего не собирает — сразу тянет готовый образ, деплой занимает около минуты.
  4. После деплоя скопируйте адрес своего сервиса, например https://astro-mcp-abc123.onrender.com, и добавьте к нему /mcp.
  5. Подключите свой URL по инструкции ниже.

💡 Бесплатный план Render: 750 часов в месяц (хватает на 24/7). Инстанс засыпает после 15 минут тишины и просыпается ~50 секунд. Чтобы не засыпал — бесплатный UptimeRobot пингует /health каждые 10 минут.

Подключение в claude.ai

  1. Откройте claude.ai → Settings → Connectors → Add custom connector (или прямо в чате: Customize → Connectors → «+»).
  2. Вставьте URL коннектора — он обязательно заканчивается на /mcp.
  3. Authentication: No authentication → Create / Connect.
  4. Готово — в новом чате доступны все 14 инструментов расчёта.

Если что-то не работает

СимптомРешение
«Authorization with the MCP server failed» URL не заканчивается на /mcp, или выбран не No authentication, или сервер спит: откройте https://<адрес>/health в браузере и дождитесь {"status":"ok"}.
Первый вызов инструмента висит Бесплатный инстанс просыпается ~50 секунд: откройте /health, дождитесь ответа, повторите запрос.
Инструменты не видны в чате Коннектор добавлен, но выключен: Customize → Connectors → включите переключатель astro-mcp.

Шаг 2

Создаём проект с вашими данными

Чтобы Claude не спрашивал данные при каждом запросе, создайте проект и один раз добавьте свою информацию.

  1. На claude.ai откройте Projects → New project, назовите, например, «Мой астролог».
  2. В блоке Project knowledge (контекст) нажмите Add content → New text и вставьте шаблон со своими данными: 
    День рождения: 1990-05-15
Время рождения: 08:30 (часовой пояс — опционально; если не знаете — напишите «не знаю»)
Место рождения: Москва, Россия
Текущее место проживания: Тбилиси, Грузия (опционально — для более точного прогноза)
  3. В поле Project instructions (инструкции) вставьте готовый промт — он заставляет Claude считать всё через MCP-сервер, а не «по памяти»: 
    Ты — профессиональный астролог-аналитик. Отвечаешь на жизненные вопросы через
астрологическую символику на основе точных расчётов.

ПРАВИЛА РАСЧЁТОВ
1. Все астрологические расчёты выполняй ТОЛЬКО через инструменты MCP-сервера
   astro-mcp. Никогда не придумывай позиции планет и не считай их по памяти.
2. Мои данные рождения бери из документов проекта: день, время и место рождения,
   текущее место жительства.
3. Если время рождения неизвестно — предупреди, что Асцендент и дома ненадёжны,
   и используй 12:00.
4. Если инструменты недоступны — остановись и попроси включить коннектор
   astro-mcp (Customize → Connectors), а не отвечай без расчётов.
5. Для прогнозов указывай диапазоны дат и орбисы аспектов; структурируй ответ
   по темам (карьера, отношения, здоровье, личный рост).
6. Не делай фаталистичных предсказаний — описывай тенденции, энергии
   и временные окна.

ИНСТРУМЕНТЫ ПО ЗАДАЧАМ
— Личность, карта рождения ......... calculate_natal_chart
— «Что сейчас происходит» .......... calculate_transits + calculate_profections
                                       + calculate_secondary_progressions
— Тема года ......................... calculate_profections + calculate_solar_return
— Отношения ......................... calculate_synastry + calculate_composite_chart
— Точные даты пиков ................. find_aspect_exact_dates
— Лучшее время для старта ........... get_planetary_hours + calculate_transits
                                       (учитывай void of course Луны)
— Неизвестное время рождения ........ calculate_rectification_hints
                                       (нужно 3–5 точных дат событий из жизни)
  4. Всё. Откройте чат внутри проекта и спрашивайте — Claude уже знает ваши данные и умеет считать.

Шаг 3

Что спросить у своего астролога

Примеры реальных запросов — каждый запускает настоящий расчёт.

Что внутри

14 инструментов расчёта на швейцарских эфемеридах (покрытие 1800–2400 гг.). Именно их Claude вызывает, отвечая на ваши вопросы.

  • calculate_natal_chartнатальная карта: планеты, углы, дома, аспекты
  • calculate_transitsтранзиты, фазы Луны, полнолуния, void of course
  • calculate_secondary_progressionsвторичные прогрессии и солнечная дуга
  • calculate_solar_returnсоляр — карта солнечного возвращения
  • calculate_lunar_returnлунар — карта лунного возвращения
  • calculate_profectionsгодовые профекции и управитель года
  • calculate_synastryсинастрия: перекрёстные аспекты и дома
  • calculate_composite_chartкомпозитная карта пары (midpoint / Дэвисон)
  • calculate_rectification_hintsвосстановление времени рождения по событиям
  • calculate_arabic_parts12 арабских точек: Фортуны, Брака, Карьеры…
  • calculate_antisciaантискии — скрытые зеркальные связи
  • get_planetary_hoursпланетные часы любого дня и города
  • get_ephemerisтаблица эфемерид, ретро-петли планет
  • find_aspect_exact_datesточные даты, когда аспект совершен

Честные ограничения

Бесплатные планы

Бесплатный Claude подключает один кастомный коннектор — этого достаточно. Render Free даёт 750 часов в месяц; инстанс спит 15 минут без трафика и просыпается ~50 секунд.

Приватность

Через общий инстанс (вариант А) проходят параметры ваших запросов — города и даты. Для полной приватности разверните свой инстанс одной кнопкой (вариант Б).

Диапазон расчётов

Файлы эфемерид покрывают 1800–2400 гг. Даты вне диапазона сервер честно отклонит.

Точность

Без времени рождения Асцендент и дома рассчитать нельзя — Claude предупредит об этом. Время можно восстановить ректификацией по датам событий жизни.
